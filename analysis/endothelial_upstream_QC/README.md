These are unchanged source scripts from the completed whole-heart, per-library snRNA QC. They were not rerun on endothelial cells in this task. scDblFinder is primary; Scrublet is diagnostic. The eight converged DecontX fits use called-nucleus clusters without empty droplets. Paths refer to the existing cloud workspace. The current endothelial-specific pipeline is in the parent analysis directory. See results/endothelial_QC_subtypes/snRNA/inherited_QC_provenance.json for original inputs, hashes and verification. The R worker script invokes snrna_decontx.R; the byte-identical frozen source is supplied here as snrna_decontx_frozen.R.
