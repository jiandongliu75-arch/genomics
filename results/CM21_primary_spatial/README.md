# Direct Xenium 21-gene CM maturation and neighboring cardiac cells

[Word report](CM21_maturation_and_neighbors.docx) · [PDF report](CM21_maturation_and_neighbors.pdf) · [Interactive21-score viewer](CM21_spatial_viewer.html) · [Narrative](Report_text.md)

All 131,605 QC-eligible ventricular CMs are retained. The sole CM maturation outcome is the directly measured 21-gene Xenium score. No anatomical restriction, inferred maturation gene program or missing-gene projection defines the outcome. Existing snRNA-supported cell identities label the neighboring populations.

The full-cohort continuous analysis, raw high/low neighborhoods and strict matched sensitivities are all provided. P7 capillary proximity has a small conditional positive relationship despite the raw high/low comparison not showing closer capillaries. P14 has concordant raw and adjusted directions. All 48 adjusted source comparisons are corrected together. Strict matched comparisons remain inconclusive. One observed section per stage limits replication.

Run cm21_primary_analysis.py, report_cm21_primary.py and validate_cm21_primary.py with the scientific Python environment; build_cm21_viewer.py and write_cm21_primary_report.py use base Python. The 21-gene panel, reconstruction checks, all-cell score/coordinate tables, source distances and confidence/coverage information are included.
